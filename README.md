## Onchain Life NFT

- Conway's game of life fully onchain with [gas killer](https://gaskiller.xyz).

### Demo

- [Onchain Life arcade machine](https://onchain-life.vercel.app)

### Contracts

- Ethereum Sepolia (testnet):

  - Onchain Life NFT: [0x9ad46609098235abC6D9f9D680F5590cdf77B2CB](https://sepolia.etherscan.io/address/0x9ad46609098235abC6D9f9D680F5590cdf77B2CB#code)
  - STEP token: [0x3924BB942434E69674A73Cd0519d3B156C367AB2](https://sepolia.etherscan.io/address/0x9ad46609098235abC6D9f9D680F5590cdf77B2CB)
  
### Env Variables

 - Copy the file `.env.sample` to `.env` and fill the following variables:

```
GAS_KILLER_ROUTER_URL=
GAS_KILLER_API_KEY=

SEPOLIA_RPC_URL=
```
